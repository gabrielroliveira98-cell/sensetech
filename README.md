# 🗑️ SenseBin · SenseTech

Landing page do **SenseBin**, uma solução **AIoT** de gestão inteligente de resíduos. O SenseBin monitora em tempo real o nível de preenchimento das lixeiras e avisa a equipe de limpeza automaticamente, para que nenhuma lixeira transborde e ninguém perca tempo com trocas desnecessárias.

> Projeto acadêmico desenvolvido em equipe no curso de Análise e Desenvolvimento de Sistemas.

![SenseBin](https://raw.githubusercontent.com/gabrielroliveira98-cell/portfolio/main/assets/sensebin-preview.png)

## ⚙️ Como a solução funciona

1. **📡 Sensor instalado:** um sensor ultrassônico fixado na tampa mede a distância até o lixo
2. **☁️ Dados na nuvem:** as leituras são enviadas por Wi-Fi para a plataforma, que guarda o histórico de cada lixeira
3. **🔔 Alerta automático:** quando a lixeira chega ao nível definido, a equipe de limpeza recebe um aviso no celular
4. **📊 Relatórios:** o gestor acompanha a frequência de uso, os horários de pico e o desempenho da equipe

## 🌐 Sobre a página

- Página única com as seções Hero, Como funciona, Benefícios, Equipe e Contato
- Simulação animada de uma lixeira enchendo e disparando o alerta
- Navegação fixa com efeito de vidro (backdrop blur) e rolagem suave
- Layout responsivo
- Feita com HTML, CSS e JavaScript puros, sem dependências

## ▶️ Como visualizar

Abra o `index.html` no navegador ou rode um servidor estático:

```bash
python -m http.server 8000
```
